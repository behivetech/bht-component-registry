# `@bht-component-registry/eslint-config`

Shared ESLint configurations for the workspace. Workspace-only; never published.

- `./base`: TypeScript, Prettier compatibility, warnings only.
- `./react-internal`: `base` plus React and hooks rules, for component packages and the shared packages.
- `./next-js`: `base` plus the Next.js plugin, for `apps/docs`.
